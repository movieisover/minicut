파일 가져오기
클릭하거나 동영상·이미지·오디오를 끌어다 놓으세요
아직 가져온 미디어가 없어요

클릭하면 재생 헤드 위치에 3초 길이 텍스트가 추가돼요.

사용법
1. 미디어 가져오기 → 썸네일을 타임라인으로 드래그 (또는 + 버튼)
2. 클립 드래그로 이동, 양 끝을 끌어서 자르기(트림)
3. 프리뷰에서 클립을 직접 드래그해 위치 이동, 휠로 크기 조절
4. 오른쪽 패널에서 필터·조정·페이드·볼륨 편집
5. 내보내기 → WebM 파일로 저장

단축키
Space 재생/정지
S 재생 헤드에서 분할
Del 선택 클립 삭제
Ctrl+D 복제
Ctrl+Z / Ctrl+Shift+Z 실행 취소/다시 실행
←→ 1프레임 이동 (Shift 1초)
Home/End 처음/끝으로
Ctrl+휠 타임라인 확대/축소
