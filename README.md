# MiniCut

브라우저에서 바로 쓰는 CapCut 스타일의 간단한 영상 편집기 (단일 `index.html`).

[OpenCut](https://github.com/OpenCut-app/OpenCut)의 편집기 구조(미디어 패널 · 프리뷰 · 속성 패널 · 멀티트랙 타임라인)를 참고해 빌드 없이 동작하도록 단순화했습니다.

## 기능
- 동영상 · 이미지 · 오디오 가져오기 (드래그 앤 드롭)
- 멀티트랙 타임라인: 이동, 트림, 분할, 복제, 삭제, 스냅, 줌, 실행 취소/다시 실행
- 텍스트 프리셋 (제목 · 자막 · 네온 등)
- 프리뷰에서 직접 위치/크기 조절, 필터 · 밝기/대비/채도, 페이드, 볼륨
- 화면 비율 16:9 · 9:16 · 1:1 · 4:5
- WebM 내보내기 (오디오 포함)

## 단축키
`Space` 재생/정지 · `S` 분할 · `Delete` 삭제 · `Ctrl+D` 복제 · `Ctrl+Z` 실행 취소 · `←/→` 프레임 이동

모든 처리는 브라우저 안에서만 이루어지며 파일이 서버로 업로드되지 않습니다. Chrome/Edge 권장.
